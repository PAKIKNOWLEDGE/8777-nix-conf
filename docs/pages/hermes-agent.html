关于 hermes agent 的安装

备忘（原文标注 20260817）。

安装脚本

↓拉取bash
curl -fsSL https://res1.hermesagent.org.cn/install.sh | bash

上面的 install.sh | bash 依旧是可用的。

强依赖与冲突

  • 这个脚本强依赖的点有：python3.11、uv
  • 而 nixpkg 的 python3 断言指向 python3.13，这个脚本一开始爬不到，会用 uv 去拉一个做 venv
  • 但是 uv 默认源比较慢，那么：

两条绕法

  1. 1手动用环境变量注入去用 uv 装 python3.11，然后让脚本跳过检测
  2. 2提前配置好 uv 的全局镜像 (recommended)
配置bash · 绕法 1
# 用国内镜像拉 python-build-standalone，再让安装脚本跳过检测
export UV_PYTHON_INSTALL_MIRROR="https://mirror.nju.edu.cn/github-release/astral-sh/python-build-standalone"
uv python install 3.11

来源可靠性

此外

https://res1.hermesagent.org.cn/install.sh 是国内的人公益维护，不一定可靠。
